### 🚀 Featured Project

#### Audit Platform | 회계·재무 데이터 분석 및 감사지원 플랫폼

자료 업로드부터 분석 실행, 원본 확인, 검토 기록, 조서 다운로드까지 연결한 웹 서비스입니다.

- **데이터 전처리**: SAP·QuickBooks 자료 변환, GL·TB 대사, 데이터 클렌징
- **감사 데이터 분석**: 총계정원장 테스트(JET), 분석적 검토, 조회 회신 비교, 자금 대사, 재고 분석
- **결과 검토**: 원본 행 추적, 자료 버전 비교, 증빙 참조 및 검토 의견 기록
- **설계·검증**: AICPA ADS를 참고한 데이터 구조 설계와 입력 검증
- **기술**: Python · FastAPI · pandas · SQLite · JavaScript · Docker · GitHub Actions
